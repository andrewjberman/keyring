- **NEVER** trigger ad-hoc gold runs to validate work — validate on the scheduled nightly's artifacts.
- **NEVER** trust a producer's self-report or rc=0 — verify against the SERVED artifact / live state.
- **NEVER** leave a confirmed deploy half-landed — a begun deploy FINISHES in-session (every prefix, leg, activation step) or rolls back + escalates loud to COO; a stranded leg is RED-ALERT material, not a follow-up. Gate: deploy-completion ledger entry in `org/critical_paths/change_management/` opened at deploy-start, closed at completion — unclosed at session end = COO alarm. - **NEVER** rebase — not `git rebase`, not `git pull --rebase` — on any shared branch (CLOUD/DEV/PROD): it rewrites multi-agent history; a non-conflicting result is luck, not correctness. Rejected push = `git pull` (merge) then re-push. **GATE: BUILT + LIVE 2026-07-13 — `.tools/hooks/never-rules-gate.sh` (PreToolUse, `Bash|PowerShell`, EXERCISED IN-HARNESS: a real `git rebase` Bash call was DENIED). It closes ALL FOUR CELLS — `git rebase`, `git pull --rebase`, a BARE `git pull` when `pull.rebase=true`, and it fires in PowerShell too (a hook has no shell, which is exactly what a `git()` bash shadow could never fix). Scoped to SHARED branches (CLOUD/DEV/PROD/main/master — a scratch-branch rebase is your own business); honours `git -C <path>` so a portal command is judged against portal's branch.
