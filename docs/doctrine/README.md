# docs/doctrine/ — principles that BIND

**What goes here:** durable principles that govern how every agent works. Stated as **rules**, in the
imperative, with no incident narrative.

**What does NOT go here:** what happened, when, to whom, and the measured numbers. That is
[`docs/references/`](../references/) — link to it, don't inline it.

## The split

| | `docs/doctrine/` | `docs/references/` |
|---|---|---|
| **Answers** | *What must I do?* | *What happened?* |
| **Tense** | Imperative, timeless | Past, dated |
| **Ages** | Only if the practice changes | Never — it is the record |
| **Example** | *"A control that cannot fail is not a control."* | *"On 2026-07-13 a shim was validated in a shell with no `.tools` on PATH…"* |

**A principle whose incident is lost is a principle the next person can talk themselves out of.** So every
doctrine entry links to the reference that earned it, and every reference links back to the doctrine it
produced. **Neither stands alone.**

## Why this is not in CLAUDE.md

CLAUDE.md is **law**, loaded into every agent's context **every turn**. Its own rule: *a rule = imperative
(≤2 lines) + enforcing gate + pointer — the why and the incident history live at the pointer.* Doctrine that
grows inside CLAUDE.md taxes every session forever. It belongs here, and CLAUDE.md points at it.
